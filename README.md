# 🛠️ 在线密码生成器工具箱

一个功能丰富的生活效率工具箱网站，包含密码生成器、待办清单、随机抽奖等实用工具，支持数据持久化、深色模式和数据导入导出功能。

## ✨ 功能特性

### 🎯 核心工具
- **🔐 在线密码生成器** - 安全随机的密码生成，支持自定义长度和字符类型，实时密码强度检测
- **📝 待办清单** - 高效任务管理，支持添加、完成、删除任务，筛选查看状态
- **🎲 随机抽奖** - 公平公正的随机抽取工具，支持多人参与

### 🎨 用户体验
- **🌙 深色/浅色模式** - 一键切换主题，适配不同使用场景
- **📊 使用统计面板** - 展示各工具使用次数、数据概览
- **📱 移动端适配** - 完美适配手机端，操作流畅

### 💾 数据管理
- **本地存储** - 所有数据自动保存到 localStorage，刷新不丢失
- **数据导入/导出** - 支持 JSON 格式备份与恢复所有工具数据

## 🚀 快速开始

### 在线访问
项目已部署到 GitHub Pages：[在线密码生成器工具箱](https://xiaoxin24444.github.io/2444-/)

### 本地运行
```bash
# 克隆仓库
git clone https://github.com/xiaoxin24444/2444-.git

# 进入目录
cd 2444-

# 使用任意 HTTP 服务器启动
# 例如使用 Python：
python -m http.server 8000

# 或使用 Node.js：
npx serve .

# 打开浏览器访问 http://localhost:8000
```

## 🛡️ 安全特性

- 使用 `crypto.getRandomValues()` 生成安全随机数
- 所有数据仅存储在浏览器本地，不上传服务器
- 支持导出数据备份，确保数据安全
